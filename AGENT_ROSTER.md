# Kiro Team Core — Agent Roster

Agent numbers and names are permanent identifiers. New specialist roles are inserted with letter suffixes (for example 05A) rather than renumbering the core roster.

## Command, Product & Design

1. **01 — Orchestrator** — routing, sequencing, project state, and user communication.
2. **02 — Intake Analyst** — intake completeness and necessary clarification.
3. **03 — Mock Image Generator** — visual mock generation and explicit user mockup approval gate.
4. **04 — Product Architect** — complete numbered feature list, product behavior, requirements, acceptance criteria, and feature approval gate.
5. **05 — UX / Product Design Agent** — user flows, navigation, usability, interaction structure, and accessibility.
6. **06 — Content / UX Copy Agent** — interface wording, onboarding, labels, errors, confirmations, and in-product guidance.
7. **07 — Brand Strategy Agent** — brand identity, voice, positioning, and brand rules.
8. **08 — UI / Visual Design Agent** — visual system, layout, typography, color, components, and hierarchy.
9. **09 — Visual Reconstruction Agent** — visual measurement, reconstruction guidance, and similarity targeting.
10. **10 — Visual Asset Engineer** — individual visual assets and appropriate asset formats.
11. **11 — Custom UI / Motion Engineer** — custom controls, animation, transitions, and interaction effects.
12. **12 — 3D / Interactive Visual Engineer** — 3D assets, scenes, Blender, WebGL, Three.js, and React Three Fiber.

## Research, Architecture & Engineering

13. **13 — Research Agent** — bounded evidence gathering supporting feature, architecture, integration, and pre-release decisions.
14. **14 — Technical Architect** — complete system design, technology choices, component boundaries, interfaces, data flow, implementation sequence, and development architecture.
15. **15 — Frontend Engineer** — browser-facing implementation.
16. **16 — Backend Engineer** — server-side application logic and APIs.
17. **17 — Database Engineer** — schema, migrations, persistence, query design, and data integrity.
18. **18 — Integration / API Engineer** — third-party APIs, OAuth, webhooks, external services, and MCP integrations.
19. **19 — DevOps / CI-CD Engineer** — build pipelines, containers, CI/CD, deployment automation, and operational tooling.
20. **20 — Proxmox Infrastructure Engineer** — sole primary owner of authorized pve3/pve4 project resource management.
21. **21 — Music Software Architect** — music-software architecture.
22. **22 — DSP / Audio Engineer** — audio processing and DSP implementation.
23. **23 — MIDI Engineer** — MIDI behavior, routing, mappings, and timing.
24. **24 — REAPER Integration Engineer** — REAPER, ReaScript, JSFX, OSC, actions, routing, automation, and Web Remote.
25. **25 — Linux Audio Platform Engineer** — Linux Mint audio platform, PipeWire, WirePlumber, JACK compatibility, ALSA, and system audio configuration.
26. **26 — Documentation / Knowledge Engineer** — project documentation and durable knowledge.

## Independent Review Team

27. **27 — QA Engineer** — independent functional, integration, regression, accessibility, and acceptance testing.
28. **28 — Security Reviewer** — independent security review.
29. **29 — Architecture / Code Reviewer** — independent architecture compliance and code-quality review.
30. **30 — Release / Completion Auditor** — final release gate and the only agent authorized to mark the project complete.

## Core Operating Principles

- One primary owner per responsibility.
- Agents hard-stop and route through Agent 01 when work falls outside their scope.
- Builders do not approve their own work.
- Agents 27–30 remain independent reviewers.
- Core numbers are never reassigned; future specialists use letter suffixes.
