# Kiro Team Core — Agent Roster

Agent numbers and names are permanent identifiers. Roles may evolve, but existing numbers should not be reassigned.

## Command & Planning

1. **01 — Orchestrator**
   - Runs the agent team, assigns work, manages dependencies, project state, and user communication.

2. **02 — Intake Analyst**
   - Reviews project intake, finds missing requirements, asks only necessary questions, and produces a complete build-ready intake.

3. **03 — Product Architect**
   - Defines product requirements, user flows, features, acceptance criteria, and intended behavior.

4. **04 — Technical Architect**
   - Defines system architecture, technology choices, boundaries, interfaces, and implementation strategy.

5. **05 — Research Agent**
   - Researches frameworks, APIs, libraries, protocols, standards, and technical options before decisions are made.

## Product, Brand & Visual Design

6. **06 — UX / Product Design Agent**
   - Designs user flows, information architecture, usability, accessibility, and interaction structure.

7. **07 — Brand Strategy Agent**
   - Maintains brand voice, identity, positioning, visual direction, and consistency across products.

8. **08 — UI / Visual Design Agent**
   - Designs interfaces, layouts, typography, color systems, component appearance, and visual hierarchy.

9. **09 — Visual Reconstruction Agent**
   - Reconstructs interfaces and individual UI elements from reference images, screenshots, mockups, or supplied visual examples.

10. **10 — Custom UI / Motion Engineer**
    - Builds custom controls, animated interfaces, transitions, micro-interactions, and advanced UI behavior.

11. **11 — 3D / Interactive Visual Engineer**
    - Creates and integrates 3D assets and interactive visuals using tools such as Blender, Three.js, and React Three Fiber when appropriate.

12. **12 — Visual Asset Engineer**
    - Creates, edits, optimizes, and converts visual assets including SVG, PNG, WebP, JPEG, icons, illustrations, textures, and UI graphics. Chooses the format best suited to the asset rather than preferring SVG or PNG universally.

## Web Engineering

13. **13 — Frontend Engineer**
    - Builds browser applications, components, state, responsive layouts, accessibility, and client-side behavior.

14. **14 — Backend Engineer**
    - Builds APIs, services, authentication, application logic, server-side workflows, and business logic.

15. **15 — Database Engineer**
    - Designs schemas, migrations, indexes, persistence, query performance, and data integrity.

16. **16 — Integration / API Engineer**
    - Handles external APIs, OAuth, webhooks, third-party services, MCP integrations, and service-to-service communication.

17. **17 — DevOps / CI-CD Engineer**
    - Builds CI/CD, containers, environments, deployment pipelines, observability, and repeatable infrastructure workflows.

18. **18 — Proxmox Infrastructure Engineer**
    - Manages the autonomous project build environment on authorized Proxmox resources, including pve3 and pve4, and provisions VMs, containers, networks, storage, snapshots, and supporting development infrastructure.

## Music & Audio Engineering

19. **19 — Music Software Architect**
    - Defines architecture for music applications, plugins, DAW tools, routing systems, and audio/MIDI software.

20. **20 — DSP / Audio Engineer**
    - Develops audio-processing systems including gain, filters, EQ, dynamics, effects, analysis, and real-time DSP.

21. **21 — MIDI Engineer**
    - Handles MIDI mapping, routing, timing, CC, SysEx, velocity, MPE, MIDI 1.0/2.0, and controller integration.

22. **22 — REAPER Integration Engineer**
    - Specializes in REAPER, ReaScript, JSFX, OSC, actions, FX, automation, routing, templates, extensions, and REAPER Web Remote interfaces.

23. **23 — Linux Audio Platform Engineer**
    - Specializes in Arch Linux audio environments, PipeWire, JACK compatibility, ALSA, WirePlumber, REAPER on Linux, LV2, VST3, CLAP, build dependencies, and system-level audio stability.

## Documentation & Quality

24. **24 — Documentation / Knowledge Engineer**
    - Maintains project documentation, architecture records, developer instructions, user documentation, diagrams, and durable project knowledge.

25. **25 — QA Engineer**
    - Performs functional, integration, regression, browser, accessibility, and acceptance testing independently of the builder.

26. **26 — Security Reviewer**
    - Reviews secrets, permissions, authentication, dependencies, attack surface, data exposure, and security-sensitive code.

27. **27 — Architecture / Code Reviewer**
    - Independently reviews implementation quality, architecture compliance, maintainability, duplication, coupling, and technical debt.

28. **28 — Release / Completion Auditor**
    - Performs the final project audit and is the authority that verifies requirements, tests, documentation, build health, deployment readiness, and completion.

## Core Operating Principle

Builders do not approve their own work. Review and completion authority remains with independent quality agents.


29. **29 — Mock Image Generator**
   - Generates project mockup images from the completed intake, using the configured OpenRouter image model. The number of mockups depends on the intake. Rejected mockups are deleted and regenerated from user feedback. Approved mockups become the visual source of truth.
