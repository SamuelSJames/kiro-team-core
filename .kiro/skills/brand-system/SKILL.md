# Brand System

## Owner
Agent 07 — Brand Strategy Agent.

## Shared Use
Agents 03, 06, 08, 10, 11, and 12 consume approved brand rules.

## Source Inspiration
Adapted from magnus919/agent-skills brand-designer, simplified for Kiro Team Core.

## Procedure
1. Confirm brand purpose, audience, positioning, personality, and differentiators from approved inputs.
2. Define a small set of durable brand attributes.
3. Define voice attributes, tone shifts by context, preferred vocabulary, and prohibited patterns.
4. Define visual identity direction at the rule level:
   - logo usage principles;
   - palette roles;
   - typography direction;
   - imagery/illustration character;
   - iconographic character.
5. Distinguish brand rules from project-specific UI decisions.
6. Provide examples and anti-examples that make the rules executable.
7. Record application rules for digital interfaces and generated visual assets.
8. Version material brand changes and record rationale.

## Output
BRAND.md and, when needed, a concise brand card.

## Hard Stop
Do not create detailed screen layouts, implement visual components, or generate final assets unless routed to the owning visual agent.
