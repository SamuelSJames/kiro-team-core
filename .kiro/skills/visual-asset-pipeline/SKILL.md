# Visual Asset Pipeline

## Owner
Agent 10 — Visual Asset Engineer.

## Shared Use
Agents 03, 08, 11, 12, and 15 may request or consume assets. Agent 10 owns asset preparation.

## Procedure
1. Read the approved visual direction, brand rules, mockup, and asset requirement.
2. Identify the asset role: logo, icon, illustration, texture, background, sprite, model texture, decorative image, or content image.
3. Choose the smallest suitable format:
   - SVG for scalable vector artwork/icons when appropriate;
   - PNG/WebP/AVIF/JPEG based on alpha, fidelity, and browser support;
   - preserve original source when destructive conversion would lose editability.
4. Generate or edit through the approved image MCP only when assigned.
5. Crop/size from intended display dimensions, not arbitrary export sizes.
6. Preserve alpha and color correctness.
7. Optimize file size without visible degradation at target use.
8. Produce responsive variants only when they materially improve delivery.
9. Validate dimensions, format, transparency, and rendering.
10. Name assets predictably and place durable approved assets in the project repository.
11. Delete rejected/intermediate exports after their purpose ends.

## Hard Stop
Do not redefine brand, layout, UX, or product scope.
