# Mockup Approval Cycle

## Owner
Agent 03 — Mock Image Generator.

## Shared Use
Agents 01, 08, and 09 may consume approved outputs. They do not own the approval cycle.

## Prerequisite
Validated intake.

## Steps
1. Determine the smallest useful mockup set from the intake.
2. Build generation prompts from approved requirements and references.
3. Use the attached OpenRouter Image MCP.
4. Save candidates only as temporary task artifacts.
5. Present candidates for explicit user approval.
6. Delete rejected/superseded candidates when no longer needed.
7. If feedback materially changes scope, stop and route back through Agent 01 to Agent 02.
8. When explicitly approved, record the approved mockup as the visual source of truth.
9. Promote only required approved assets to the project's designated repository.

## Hard Stop
Do not begin implementation or treat implied preference as explicit approval.
