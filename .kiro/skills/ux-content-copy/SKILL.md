# UX Content & Copy

## Owner
Agent 06 — Content / UX Copy Agent.

## Shared Use
Agents 05, 07, 08, 15, and 27 consume approved interface copy.

## Procedure
1. Read approved product behavior, UX flows, states, and brand voice.
2. Write copy for:
   - navigation labels;
   - buttons/actions;
   - form labels and help;
   - validation/error messages;
   - empty/loading/success states;
   - destructive confirmations;
   - permission/access messages;
   - onboarding/instructional text.
3. Make actions explicit and outcome-oriented.
4. Prefer plain language and concrete nouns/verbs.
5. Keep labels short; move explanation into supporting text when needed.
6. Make errors answer: what happened, what can the user do next, and whether data was lost.
7. Avoid blame, vague failure text, jargon, and cleverness that reduces clarity.
8. Apply Agent 07's brand voice without weakening usability.
9. Check copy at realistic lengths so layout problems surface before implementation.
10. Record approved strings or patterns in CONTENT_SPEC.md.

## Hard Stop
Do not change feature behavior, UX structure, brand strategy, or visual design to accommodate copy.
