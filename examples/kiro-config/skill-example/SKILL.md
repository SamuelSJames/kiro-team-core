# Example Skill

## Owner

Declare exactly one primary owning agent before promoting this skill into the active team.

## Purpose

Provide a short, repeatable workflow without loading unrelated project context.

## Steps

1. Read only the inputs required for this task.
2. Validate prerequisites.
3. Perform the narrowly defined operation.
4. Verify the result.
5. Return a concise handoff to the owning agent.

## Hard Stop

If the task expands beyond this skill's purpose, stop and return control to the owning agent. Do not absorb another skill's responsibility.
